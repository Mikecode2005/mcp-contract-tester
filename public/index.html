Open-source developer tooling · v0.1.0

Catch broken MCP contracts before the client does.

A local, dependency-free CLI for validating tool schemas, recording JSONL traces, and generating reports you can attach to a pull request.

Read the README

Ready with a deliberately small contract.

terminal
$ npx mcp-contract-tester validate tools.json
PASS · 2 tools · 0 errors · 1 warning
  WARNING tool.description.short: Tool 2 description is very short

$ npx mcp-contract-tester report tools.json --out report.html
Wrote report.html
01

Validate

Find malformed names, missing descriptions, duplicate tools, and schema mismatches.

02

Record

Explain

Turn findings into a standalone HTML report that is easy to share in review.
