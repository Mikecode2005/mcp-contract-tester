# Contributing

Thanks for helping make MCP tooling safer and easier to test.

## Development

1. Install Node.js 20 or newer.
2. Run `npm test`.
3. Run `npm run check` before opening a pull request.

## Pull requests

Keep changes focused, add a regression test for new validation rules, and describe the contract shape used by the test fixture. Please do not include real credentials, private prompts, or production traces in issues or pull requests.

## Good first contributions

- Add a validator rule with a fixture and test.
- Improve the CLI error message for an invalid option.
- Add a report accessibility improvement.
- Add examples for another JSON-RPC response shape.
