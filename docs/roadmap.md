# Roadmap

## 0.1 shipped

- Local tools/list validation
- JSONL trace recording and inspection
- Standalone HTML reports
- Node 20 test and syntax checks

## Next

- stdio discovery with an explicit opt-in command
- stronger JSON Schema compatibility checks
- snapshot comparison between server versions
- GitHub Action annotations
- trace summaries for latency and failure counts

## Later

- adapters for additional MCP transports
- a stable plugin API for organization-specific rules
- redaction policies for sensitive trace fields

The project will stay local-first and dependency-light unless a feature clearly earns a new dependency.
