# Contributor Covenant Code of Conduct

We want this project to be a welcoming place for people exploring AI tooling and protocol development. Participants are expected to be respectful, assume good intent, give actionable feedback, and protect private data shared during debugging.

Unacceptable behavior includes harassment, discrimination, doxxing, personal attacks, and publishing credentials or private traces. Maintainers may remove comments, close issues, or restrict participation when needed to keep the project safe.

Report conduct concerns privately to the maintainer listed on the GitHub profile.
